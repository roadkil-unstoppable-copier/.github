# Unstoppable Copier - Copy Files That Skip Bad Spots

## When a Normal Copy Stops

Explorer cancels a folder when one file will not read. Unstoppable Copier can retry that file, skip the unreadable part, and continue with the rest. A skipped piece means the copy is incomplete. A photo may still open. A database may not. Look at the log before you delete the originals.

Use it when the drive is slow but still mounted. If the disk clicks and vanishes, more copy passes can make it worse. Grab the most important folders first, not the entire drive in one heroic job.

## Settings That Matter

| Choice | Effect |
|---|---|
| Destination on another disk | The source is not written more than the reads require |
| Retry count | Higher spends time on a bad file |
| Skip bad sectors | The file continues with a hole |
| Log | Which files are incomplete |
| Whole-drive mode | Longer, and less kind to a dying disk |

## Steps

1. Copy the most important folder first, to a healthy disk.  
2. Read the log for skipped files.  
3. Open those copies. Keep them only if they are usable.  
4. Then copy the next folder.  
5. Do not format the source because the first folder succeeded.

## Fits

A scratched disc or a disk with a few bad files, when you can still see the folders. A poor fit for a drive that disappears from the PC. A poor fit for a full image of a system disk. A poor fit for encrypted files you cannot open even if every byte copies.

## Requirements

| Item | Expectation |
|---|---|
| Source | Mounted, yours to read |
| Destination | Different media with room |
| Time | Retries are slow |
| Judgment | Incomplete files checked before you trust them |

## Fixes

The job is no faster than Explorer. The disk is waiting on bad sectors. That is the retry.  
Every file is flagged. Stop. The disk is worse than a few bad files.  
Copies will not open. The skipped parts were the content. The log was right.  
The destination fills up. Free space there and continue. Do not point the copy back at the source.  
You wanted SMART data. This tool copies files. It does not read health counters.

## Important Folders First

Make a short list: documents, photos, one project. Run those. A full-disk pass on a drive that already struggled will sit on a movie you can replace and never reach the tax folder. The log from the small jobs tells you whether a longer run is worth the wear.

## Stop When the Disk Drops

If the source disappears from Explorer, end the job. Reconnecting and starting over can be the read that finishes a weak drive. The files already on the healthy disk stay there. Check those first. A later session, if the disk returns, should copy a different folder, not retry the same bad file for an hour.

| Event | Action |
|---|---|
| One file skipped | Open the copy, keep it only if it works |
| Disk vanishes | Stop |
| Destination full | Free space, do not write back to the source |
| First folder is good | Do not format the source yet |
